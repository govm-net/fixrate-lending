# 测试用例文档

## 1. 概述

本文档详细描述了FixRate借贷平台智能合约的所有测试用例，包括现有测试用例和建议增加的边界测试用例。测试覆盖了PersonalChecker、FixedRateLendingPool、UnifiedMatchingEngine和LiquidityMining四个核心合约。

## 2. 测试用例详情

### 2.1 PersonalChecker合约测试

#### 2.1.1 现有测试用例

1. **部署测试**
   - 验证PersonalChecker合约成功部署

2. **Checker信息测试**
   - 验证getCheckerInfo函数返回正确的名称和版本

3. **出借人订单验证测试**
   - 验证具有有效签名的出借人订单能通过验证

4. **借款人订单验证测试**
   - 验证具有有效签名的借款人订单能通过验证

#### 2.1.2 建议增加的边界测试用例

1. **无效签名测试**
   - 使用无效签名验证订单应返回false

2. **过期订单测试**
   - 使用过期时间戳的订单应返回false

3. **空签名测试**
   - 使用空签名验证订单应返回false

4. **错误签名者测试**
   - 使用非订单相关方的签名应返回false

### 2.2 FixedRateLendingPool合约测试

#### 2.2.1 现有测试用例

1. **部署和初始化测试**
   - 验证合约正确设置初始参数
   - 验证所有者能够设置撮合引擎地址
   - 验证非所有者不能设置撮合引擎地址

2. **代币支持管理测试**
   - 验证所有者能够添加支持的代币
   - 验证非所有者不能添加支持的代币

3. **价格获取测试**
   - 验证能够正确获取代币价格
   - 验证对不支持代币的回退处理

4. **抵押品价值计算测试**
   - 验证能够正确计算代币价值
   - 验证对不支持代币的回退处理

5. **存款功能测试**
   - 验证用户能够存款
   - 验证没有足够余额的用户不能存款
   - 验证没有足够授权的用户不能存款

6. **提款功能测试**
   - 验证用户能够提款
   - 验证用户提款时超过其余额会被调整为实际余额

#### 2.2.2 建议增加的边界测试用例

1. **不支持的代币存款测试**
   - 尝试存入不支持的代币应失败

2. **零金额存款/提款测试**
   - 尝试存入或提款零金额的行为测试

3. **最大值测试**
   - 测试使用极大数值进行存款/提款的边界情况

4. **重复添加代币测试**
   - 尝试重复添加同一代币应如何处理

5. **删除不存在代币测试**
   - 尝试删除不存在的代币应如何处理

6. **价格预言机故障测试**
   - 模拟价格预言机返回异常值时的处理

7. **添加零地址代币测试**
   - 尝试添加零地址作为代币应失败

8. **添加零地址价格预言机测试**
   - 尝试添加零地址作为价格预言机应失败

9. **更新价格预言机测试**
   - 验证所有者能够更新代币价格预言机
   - 验证非所有者不能更新代币价格预言机
   - 验证不能为不支持的代币更新价格预言机
   - 验证不能更新为零地址价格预言机
   - 验证不能为零地址代币更新价格预言机

### 2.3 UnifiedMatchingEngine合约测试

#### 2.3.1 现有测试用例

1. **Checker授权机制测试**
   - 验证所有者能够授权Checker合约
   - 验证非所有者不能授权Checker合约
   - 验证所有者能够取消授权Checker合约
   - 验证非所有者不能取消授权Checker合约
   - 验证不能使用未授权的Checker合约执行借款交易
   - 验证不能使用未授权的Checker合约执行出借交易

2. **订单匹配和执行测试**
   - 验证能够匹配和执行订单
   - 验证订单执行后状态正确更新

3. **PoolChecker功能测试**
   - 验证能够使用PoolChecker执行借款交易

#### 2.3.2 建议增加的边界测试用例

1. **重复订单执行测试**
   - 尝试执行已处理过的订单应失败

2. **过期订单执行测试**
   - 尝试执行过期订单应失败

3. **无效签名订单测试**
   - 尝试执行带有无效签名的订单应失败

4. **错误交易发送者测试**
   - 验证只有正确的交易发送者才能执行订单

5. **并发订单测试**
   - 测试同时提交多个订单的处理情况

6. **边界参数测试**
   - 使用极值参数测试订单执行

7. **零地址Checker授权测试**
   - 尝试授权零地址作为Checker应失败

8. **还款功能测试**
   - 验证能够成功还款
   - 验证非借款人不能还款
   - 验证非活跃订单不能还款

9. **清算功能测试**
   - 验证不能清算未到期的贷款
   - 验证能够清算已到期的贷款
   - 验证非活跃订单不能清算

### 2.4 LiquidityMining合约测试

#### 2.4.1 现有测试用例

1. **合约部署测试**
   - 验证正确初始化合约参数

2. **池管理测试**
   - 验证所有者能够添加新的质押池
   - 验证所有者能够设置池的分配点数
   - 验证拒绝非所有者添加池或设置池参数

3. **质押和提取测试**
   - 验证用户能够质押代币
   - 验证用户能够提取质押的代币
   - 验证拒绝提取超过质押数量的代币

4. **奖励计算和领取测试**
   - 验证正确计算用户待领取奖励
   - 验证用户能够领取奖励
   - 验证多个用户按质押比例分配奖励

5. **紧急操作测试**
   - 验证用户能够紧急提取质押代币
   - 验证所有者能够紧急提取奖励代币

6. **暂停功能测试**
   - 验证所有者能够暂停和恢复质押
   - 验证所有者能够暂停和恢复提取
   - 验证所有者能够暂停和恢复领取奖励

#### 2.4.2 建议增加的边界测试用例

1. **时间边界测试**
   - 在挖矿开始前和结束后尝试质押/提取/领取奖励

2. **零分配点数测试**
   - 测试分配点数为零的池的行为

3. **极大分配点数测试**
   - 测试使用极大分配点数的池的行为

4. **负奖励余额测试**
   - 测试合约奖励代币余额不足时的处理

5. **多池奖励分配测试**
   - 测试多个池之间的奖励分配正确性

6. **长时间质押测试**
   - 测试用户长时间质押后的奖励计算精度

7. **合约部署边界测试**
   - 验证不能使用零地址作为奖励代币
   - 验证不能设置过去的开始时间
   - 验证不能设置结束时间早于开始时间

8. **池管理边界测试**
   - 验证不能添加零地址的LP代币
   - 验证不能设置不存在的池
   - 验证不能设置零奖励发放速率

9. **质押和提取边界测试**
   - 验证不能质押零金额
   - 验证不能提取零金额
   - 验证不能质押到不存在的池
   - 验证不能从不存在的池提取
   - 验证不能在质押暂停时质押
   - 验证不能在提取暂停时提取

10. **奖励领取边界测试**
    - 验证不能领取不存在池的奖励
    - 验证不能在领取暂停时领取奖励
    - 验证在合约奖励不足时无法领取奖励

11. **紧急操作边界测试**
    - 验证不能紧急提取不存在池的质押代币
    - 验证不能紧急提取零余额的质押代币
    - 验证不能非所有者紧急提取奖励代币
    - 验证不能紧急提取超过合约余额的奖励代币

## 3. 总结

以上测试用例涵盖了当前合约的主要功能和部分边界情况。建议增加的边界测试用例将进一步提高合约的健壮性和安全性，确保在各种异常情况下合约都能正确处理。
